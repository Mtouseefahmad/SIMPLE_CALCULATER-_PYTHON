Simple Calculator - Python

A collection of small, menu-driven Python programs built for practice, written and run in a Jupyter Notebook. Includes a calculator, a number guessing game, a grade statistics tool, and a factorial calculator.

Programs Included
1. Simple Calculator

A menu-driven calculator that performs basic arithmetic operations.

Add, subtract, multiply, divide
Handles division by zero
Runs in a loop until the user chooses to exit

How to Run
Clone or download this repository
Open calculater.ipynb in Jupyter Notebook or JupyterLab
Run the cells one by one — each cell is a separate program
bash
git clone https://github.com/Mtouseefahmad/SIMPLE_CALCULATER-_PYTHON.git
cd SIMPLE_CALCULATER-_PYTHON
jupyter notebook calculater.ipynb
Requirements
Python 3
Jupyter Notebook (no external libraries needed — only the built-in random module is used)
